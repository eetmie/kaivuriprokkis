DATA FORMATS
------------
  CSV Format:
    - Structure: [timestamp_us,]w,x,y,z,gx,gy,gz[,w,x,y,z,gx,gy,gz,...]
    - 7 values per IMU (quaternion + gyro)
    - Optional leading timestamp in microseconds
    - Human readable, easy to debug

  Binary Format:
    - Frame: 0xAA 0x55 | ver(1) | count(1) | ts_us(4) | payload | checksum(2)
    - Payload: 7 floats (28 bytes) per IMU
    - Lower overhead, faster parsing
