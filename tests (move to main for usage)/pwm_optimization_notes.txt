Per-channel write overhead:
  1. bytearray(5) allocation - NEW ALLOCATION EACH TIME
  2. struct.pack_into()
  3. I2CDevice.__enter__: try_lock() + sleep(0) spin-wait
  4. i2c.write(buf) - actual I2C transaction
  5. I2CDevice.__exit__: unlock()

At 100Hz with 8 channels = 800 allocations/sec, 800 I2C transactions/sec

===========================================================================
DIRECT I2C OPTIMIZATION IDEA
===========================================================================

PCA9685 supports auto-increment mode (already enabled by Adafruit).
Can write all channels in ONE I2C transaction.

Registers:
  0x06 = LED0_ON_L  (start of PWM registers)
  Each channel = 4 bytes: ON_L, ON_H, OFF_L, OFF_H
  16 channels × 4 bytes = 64 bytes total

Direct implementation concept:

```python
import board
import busio

class DirectPCA9685:
    def __init__(self, i2c_bus, address=0x40):
        self._i2c = i2c_bus
        self._addr = address
        # Pre-allocated buffer: 1 addr + 4 bytes × 16 channels
        self._buf = bytearray(1 + 4 * 16)
        self._buf[0] = 0x06  # LED0_ON_L register

    def set_all_duty_cycles(self, duty_cycles):
        """Update all channels in single I2C transaction.

        Args:
            duty_cycles: list of 16-bit duty cycle values (0-65535)
        """
        for i, duty in enumerate(duty_cycles):
            if duty >= 0xFFF0:
                # Fully on
                on_val, off_val = 0x1000, 0
            elif duty < 0x0010:
                # Fully off
                on_val, off_val = 0, 0x1000
            else:
                on_val = 0
                off_val = duty >> 4  # 16-bit to 12-bit

            offset = 1 + i * 4
            self._buf[offset] = on_val & 0xFF
            self._buf[offset + 1] = (on_val >> 8) & 0xFF
            self._buf[offset + 2] = off_val & 0xFF
            self._buf[offset + 3] = (off_val >> 8) & 0xFF

        # Single I2C transaction for all channels!
        while not self._i2c.try_lock():
            pass
        try:
            self._i2c.writeto(self._addr, self._buf)
        finally:
            self._i2c.unlock()

    def set_channel(self, channel, duty_cycle):
        """Update single channel (for compatibility)."""
        # Could implement partial buffer write if needed
        pass
```

Expected benefits:
  - 1 I2C transaction instead of 8-16
  - Zero allocations in hot path (pre-allocated buffer)
  - No per-channel lock overhead
  - ~8-16x less I2C bus time
